# Typography Robustness of the Deterministic Core

> Generated by `evaluation/typography_robustness.py`. Deterministic, LLM-free, reproducible without an API key.
> Corpus: `tests/data/mis_styled/` — 3 logical structures (cjk_paper, deep, report) x 8 typographies = 24 DOCX documents,
> regenerate with `python scripts/manual/create_mis_styled_docs.py`.
> Scoring: `evaluation/metrics.py` discipline (|block_id delta| <= 3 and title Levenshtein >= 0.6).
> `level accuracy` is computed on matched pairs only; `exact` counts documents whose (level, title) sequence equals GT exactly.
> `oracle` supplies every GT heading as a perfectly aligned vote with the correct level — an upper bound on any model, not a measurement of one.
> `flat_votes` supplies the same perfectly aligned votes but says `L1` for every heading — the observed behaviour of a real deployed model on typography that states no depth.
